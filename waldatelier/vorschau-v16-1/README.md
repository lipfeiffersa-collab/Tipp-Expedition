# Nachthimmel – Version 16.1

Tatsächliche Nachtansichten aus dem exportierten Spiel: Dünen, Felsen und Palmen begrenzen die Himmelsfläche. Die Bilder mit `blick` im Namen zeigen den Übergang beziehungsweise den vollständigen Himmelsblick mit O. Ein eigenständiger Bildrand wird beim Blick nach oben nicht in die Szene geschoben.
