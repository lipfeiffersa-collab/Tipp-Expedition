# Sturmfahrt – Version 21

Echte Aufnahmen aus dem mit Tastatur durchgespielten Level. Der längere Deckabschnitt führt über niedrigen Segelbaum, Waten, Festhalten, Leiter, Treppe und Wantennetz. Nach dem Deckbruch folgen Schiffsrumpf, Kriechen, Tauziehen und Untergang.

Für den direkten Einstieg das ZIP entpacken und Schiff-Test.html öffnen. Der Schiffsstart verwendet einen eigenen Testspielstand. F7 schaltet die Schiffbewegung aus/ein.
