# Tipp-Expedition – Downloads

## Aktuelle Version 12

**[Tipp-Expedition-v12.zip herunterladen](Tipp-Expedition-v12.zip)**

Auf GitHub die ZIP-Datei öffnen und „Download raw file“ anklicken. Anschließend vollständig entpacken und **Wald-Spiel.html** öffnen.

Für vorhandene Spielstände denselben Browser, Dateinamen und Speicherort verwenden. Die bisherige Datei vorher sichern.

Neu: häufigere Waldtiere, ein gesperrter Ruinenpfad mit drei Rehen an einer Futterkrippe, kurze Tier- und Truhensequenzen, weiches Abendlicht, motivgetreue Bodenfotos, korrigierte frühe Hüttenschilder sowie Verbesserungen an Nachtpfad und Höhlengrafik.

Die Futterkrippe wird erst nach fünf Schneckenhäusern und dem gelösten Wappenschloss erreichbar. Pro Fütterung oder Streicheln zieht genau ein Reh weiter. Sequenzen können mit Leertaste beendet werden.

Der bearbeitbare Quellstand und die Prüfscripte liegen in `../waldatelier/`. Das vollständige Spiel liegt zusätzlich als `../Tipp-Expedition-4.7-Waldatelier.html` vor.
